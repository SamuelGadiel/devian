# Convenções de Nomenclatura

| Artefato                                    | Convenção                                                                                                                                                                                                                                                                    | Exemplo                                                                                     |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Entidade (`domain`)                         | Nome base, sem sufixo                                                                                                                                                                                                                                                        | `User`                                                                                      |
| Abstração (repository, datasource, usecase) | Nome base, sem prefixo (`I`) nem sufixo                                                                                                                                                                                                                                      | `AuthRepository`, `AuthRemoteDatasource`, `Login`                                           |
| Implementação                               | Nome base + `Implementation` (nunca `Impl`)                                                                                                                                                                                                                                  | `AuthRepositoryImplementation`, `AuthRemoteDatasourceImplementation`, `LoginImplementation` |
| Mapper                                      | Entidade + `Mapper`, métodos estáticos                                                                                                                                                                                                                                       | `UserMapper.toJson()` / `UserMapper.fromRemoteJson()`                                       |
| Usecase                                     | Verbo puro, sem a palavra `Usecase` na classe. Abstração + implementação no mesmo arquivo, em `domain/usecases/`. Método único `call()`                                                                                                                                      | `Login` (abstração) / `LoginImplementation` (impl), ambas em `login.dart`                   |
| Failure                                     | Descrição do erro + `Failure`, implementa `Failure` do projeto (`core/errors/failure.dart`, `implements`, nunca `extends`)                                                                                                                                                   | `InvalidCredentialsFailure`                                                                 |
| Bloc                                        | `<Nome>Bloc` em `presentation/blocs/<nome>_bloc/` (3 arquivos: bloc, events, states). `<Nome>` é o módulo ou uma ação específica, conforme o critério de coerência de estado (ver [architecture.md](architecture.md#um-bloc-por-fluxo-coerente-não-por-módulo-nem-por-ação)) | `AuthBloc`                                                                                  |
| Evento (sealed base)                        | `<Nome>Events` (mesmo `<Nome>` do Bloc)                                                                                                                                                                                                                                      | `AuthEvents` (em `auth_events.dart`)                                                        |
| Evento (case)                               | Nome da ação + `Event`                                                                                                                                                                                                                                                       | `LoginEvent`, `RecoverPasswordEvent`, `LogoutEvent`                                         |
| Estado (sealed base)                        | `<Nome>States` (mesmo `<Nome>` do Bloc)                                                                                                                                                                                                                                      | `AuthStates` (em `auth_states.dart`)                                                        |
| Estado (case)                               | Ação + situação + `State`                                                                                                                                                                                                                                                    | `LoginLoadingState`, `LoginSuccessState`, `LoginFailureState`                               |
| Datasource local                            | Módulo + `LocalDatasource` — abstração em `infrastructure/datasources/`, `LocalDatasourceImplementation` em `external/datasources/local/`                                                                                                                                    | `AuthLocalDatasource` / `AuthLocalDatasourceImplementation`                                 |
| Datasource remoto                           | Módulo + `RemoteDatasource` — abstração em `infrastructure/datasources/`, `RemoteDatasourceImplementation` em `external/datasources/remote/`                                                                                                                                 | `AuthRemoteDatasource` / `AuthRemoteDatasourceImplementation`                               |
| Arquivo de binds (DI)                       | `<module>_binds.dart` em `core/service_locator/binds/`, classe `<Module>Binds` (registra no construtor)                                                                                                                                                                      | `auth_binds.dart` → `AuthBinds`                                                             |
| Arquivo de rotas                            | Agregador único `core/router/router.dart`; cada módulo em `core/router/routes/<module>_routes.dart`                                                                                                                                                                          | `core/router/routes/auth_routes.dart`                                                       |
| Constantes de rota de navegação             | Classe única e global `Routes`, em `core/router/routes.dart`; campos `static const String` em `lowerCamelCase`                                                                                                                                                              | `Routes.home`, `Routes.contactsNew`                                                          |
| Constantes de rota de API                   | Classe única e global `ApiRoutes`, em `core/network/api_routes.dart`; campos `static const String` em `lowerCamelCase`                                                                                                                                                      | `ApiRoutes.login`                                                                             |
| Página                                      | Nome + `Page`                                                                                                                                                                                                                                                                | `LoginPage`                                                                                 |
| Widget                                      | Nome descritivo + sufixo `Widget` (evita ambiguidade com entidade/outro artefato)                                                                                                                                                                                            | `LoginFormWidget`                                                                           |
| Arquivo                                     | Sempre `snake_case`                                                                                                                                                                                                                                                          | `login.dart` (usecase), `auth_bloc.dart`                                                    |
| Teste                                       | Mesmo nome do arquivo de produção + `_test.dart`, espelhando a estrutura de `lib/` em `test/`                                                                                                                                                                                | `login_test.dart`                                                                           |

Para os modificadores de classe Dart 3 associados a cada artefato (`final`, `sealed`, `abstract interface class`, etc.), ver [class_modifiers.md](class_modifiers.md).
